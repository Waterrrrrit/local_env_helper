# local_env_helper
An AI-powered diagnostic tool that analyzes local Python environments and source code to predict and resolve environment-specific errors using the Gemini API.

## Overview
An AI-powered, two-step diagnostic tool designed to extract local Python environment configurations and predict environment-specific runtime errors using the Google Gemini API.

## Architecture & Workflow
The tool operates in two sequential stages using distinct scripts:

* **1. `env_noticer.py` (Environment Profiler):** Scans the local development environment—including OS details, Python interpreter version, system paths, encodings, environment variables, and installed packages—and exports this summary to a file (e.g., `env_report.txt` or `env_summary.json`).
* **2. `env_helper.py` (AI Analyzer):** Takes the environment summary generated by `env_noticer.py` and the target Python source code as inputs. It utilizes the Gemini API to analyze the context and predict potential runtime issues (e.g., missing modules, version conflicts, encoding errors) specific to that exact local setup.

## Key Features
* **Automated Context Extraction:** Securely structures system and Python-specific configurations without external dependencies.
* **AI-Driven Troubleshooting:** Employs the latest `google-genai` SDK to evaluate code logic against the hardware and software environment.
* **Pre-execution Debugging:** Proactively identifies environment-dependent errors and provides actionable solutions before code execution.

## Prerequisites
* Python 3.x
* `google-genai` library (`pip install google-genai`)
* Google Gemini API Key
